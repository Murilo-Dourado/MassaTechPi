#Cliente:#

Entra no site, vê o cardápio (separado por categorias básicas).

Adiciona itens ao carrinho.

Na hora de fechar, o sistema pede para ele fazer um cadastro rápido ou login.

Escolhe a forma de pagamento (Dinheiro, Cartão ou Pix) e o endereço.

Finaliza o pedido (o pedido vai para o banco de dados e limpa o carrinho).

Consegue ver uma tela de "Meus Pedidos" para acompanhar o status (ex: "Preparando", "Saiu para entrega").

Funcionário / Cozinha / Atendente (Painel Único):

Uma página restrita onde o funcionário da pizzaria loga.

Vê uma tabela simples com os pedidos que os clientes fizeram.

Tem botões simples para atualizar o status do pedido (Ex: de "Pendente" para "Em Preparo", depois "Saiu para Entrega").
